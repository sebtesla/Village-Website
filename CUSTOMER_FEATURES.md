# Customer Features Guide

Guide for customers using The Village Merch Store features.

## 📦 Order Tracking

### Access Order Tracking

**Multiple Ways to Access:**

1. **From Footer** → Click "Track Order" link
2. **From Checkout Success** → Click "Track Your Order" button
3. **Direct URL** → Visit `/track-order`

### How to Track Your Order

1. **Visit Tracking Page**
   - Go to the Track Order page

2. **Enter Order Details**
   - **Order Number**: Found in your confirmation email (e.g., VLG-ABC123-XYZ)
   - **Email Address**: The email you used at checkout

3. **View Order Status**
   - Click "Track Order" button
   - See complete order information

### What You'll See

**Order Status**
- Current order status with description
- Visual progress bar
- Status timeline with icons

**Order Information**
- Order number
- Customer email
- Order total
- Items ordered with images
- Quantities and prices

**Tracking Details (when available)**
- Tracking number
- Link to track package
- Shipment date
- Estimated delivery (if shipped)

**Order Timeline**
- When order was placed
- When payment was confirmed
- When order shipped
- When order delivered

### Order Status Meanings

**Pending Payment** 🕐
- Waiting for payment to process
- Order created but not yet paid

**Payment Confirmed** ✅
- Payment successful
- Order being prepared

**Processing** 📦
- Order is being prepared for shipment
- Items are being packed

**Shipped** 🚚
- Order has been shipped
- Package is on the way
- Tracking number available

**Delivered** ✅
- Package has been delivered
- Order complete

**Cancelled** ❌
- Order has been cancelled
- Contact support for refund

### Using Tracking Number

When your order ships, you'll see:
- **Tracking Number**: Unique package identifier
- **Track Package Button**: Opens tracking in new window
- **Shipped Date**: When package left our facility

**Track Package:**
1. Click "Track Package" button
2. Opens Google search with tracking number
3. Or copy tracking number
4. Use on carrier's website (USPS, UPS, FedEx)

### Order Timeline Details

**See Complete History:**
- ✅ Order Placed - When you completed checkout
- ✅ Payment Confirmed - When payment processed
- 🚚 Shipped - When package sent (if applicable)
- ✅ Delivered - When package received (if applicable)

Each event shows:
- Event type with icon
- Date and time
- Description

### Tracking Tips

**Order Number Not Working?**
- Check your confirmation email
- Copy and paste to avoid typos
- Order number format: VLG-XXXXX-XXX

**Email Not Working?**
- Use the same email from checkout
- Check for typos
- Try lowercase

**Order Not Found?**
- Wait a few minutes after placing order
- Check confirmation email for correct details
- Contact support if issue persists

**Need Help?**
- Join our Discord community
- Check order status regularly
- Contact support with order number

## 📧 Email Notifications

### Order Confirmation Email

**When You Receive It:**
- Immediately after successful payment

**What's Included:**
- Order number
- Complete item list with images
- Prices and totals
- Shipping information
- What happens next

**Save This Email:**
- Contains your order number
- Needed for order tracking
- Reference for support

### Shipping Confirmation Email

**When You Receive It:**
- When your order ships

**What's Included:**
- Order number
- Tracking number
- Link to track package
- Estimated delivery date
- Delivery instructions

**Action Required:**
- Click tracking link to monitor package
- Be available for delivery
- Check delivery instructions

### Email Troubleshooting

**Didn't Receive Confirmation?**
- Check spam/junk folder
- Wait 5-10 minutes
- Verify email address at checkout
- Contact support

**Didn't Receive Shipping Email?**
- Order may still be processing
- Check order status on tracking page
- Shipping email sent when tracking added
- Contact support if delayed

### Checkout Process

**Requirements:**
- Must sign in with Discord
- No guest checkout
- Secure payment via Stripe

**Steps:**
1. Add items to cart
2. Click "Proceed to Checkout"
3. Sign in with Discord (if not logged in)
4. Redirected to Stripe Checkout
5. Enter payment information
6. Complete purchase
7. Receive confirmation email

**Payment Options:**
- Credit cards (Visa, Mastercard, Amex, Discover)
- Secure SSL encryption
- Powered by Stripe

### After Purchase

**Within 3-5 Days:**
