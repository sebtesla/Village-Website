# 📸 Quick Image Upload Guide

## 🚀 5-Minute Setup

### Step 1: Upload to Imgur (2 min)

1. Go to: **https://imgur.com/upload**
2. Drag your product photo onto the page
3. Wait for upload to complete
4. Right-click the image → **Copy image address**

You'll get: `https://i.imgur.com/ABC123.jpg`

---

### Step 2: Add to Admin Panel (3 min)

1. Go to: **https://therustvillage.netlify.app/admin/products**
2. Enter password: `admin123`
3. Click **"Add Product"**
4. Fill in:

```
Name: The Village Hat (Green)
Price: 35.00
Description: Our signature snapback hat...

Images (paste URLs, one per line):
https://i.imgur.com/ABC123.jpg
https://i.imgur.com/DEF456.jpg

Sizes: (optional, comma separated)
(leave empty for one-size items like hats)

Colors: (comma separated)
Green, Black, Navy

Category:
hats (or apparel, or accessories)

Features: (one per line)
Embroidered logo
Adjustable strap
Premium cotton
```

5. Click **"Create Product"** ✅

## 💡 Pro Tips

**Multiple Images:**
Upload 3-5 images per product:
```
https://i.imgur.com/FRONT.jpg    ← Main image (shows first)
https://i.imgur.com/BACK.jpg
https://i.imgur.com/DETAIL.jpg
https://i.imgur.com/WORN.jpg
```

**Image Names:**
Keep organized:
- `village-hat-green-front.jpg`
- `village-hat-green-back.jpg`
- `village-hoodie-black-main.jpg`

**Imgur Tips:**
- Upload individual images (not albums)
- Right-click → "Copy image address"
- URL must end in `.jpg` or `.png`
- Make sure URL starts with `https://i.imgur.com/`

**Image not showing?**
✅ Check URL ends with `.jpg` or `.png`
✅ Check URL starts with `https://i.imgur.com/`
✅ Try opening URL in browser (should show just the image)

**Can't access admin?**
✅ Password is: `admin123`
✅ Go to: `/admin/products`

**Product not in shop?**
✅ Make sure "In Stock" is checked
✅ Wait a minute and refresh
