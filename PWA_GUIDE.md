# Progressive Web App (PWA) Guide

The Village Merch Store is now a **Progressive Web App** - users can install it on their devices for an app-like experience!

## 🎯 What is a PWA?

A Progressive Web App combines the best of web and mobile apps:

**Web Benefits:**
- No app store approval needed
- Instant updates (no downloads)
- Works on all platforms
- Single codebase

**App Benefits:**
- Installable on home screen
- Works offline
- Fast loading
- Push notifications
- Full-screen experience

## 📱 User Experience

### Installation Process

**On Android (Chrome/Edge):**
1. Visit the website
2. See install prompt after 5 seconds
3. Tap "Install App" button
4. App adds to home screen
5. Launch like any other app

**On iOS (Safari):**
1. Visit the website
2. See install instructions after 5 seconds
3. Tap Share button (📤)
4. Scroll and tap "Add to Home Screen"
5. Tap "Add" to confirm
6. App icon appears on home screen

**On Desktop (Chrome/Edge):**
1. Visit the website
2. See install icon in address bar
3. Click to install
4. App launches in its own window

## 🔧 Technical Implementation

### What We Added

**1. Manifest File** (`/public/manifest.json`)
- App name and description
- Icon sizes for all devices
- Theme colors
- Display mode (standalone)
- App shortcuts
- Screenshots

**2. Service Worker** (Auto-generated by next-pwa)
- Caches pages and assets
- Enables offline functionality
- Network-first strategy
- Background sync

**3. Install Prompt** (`/src/components/pwa-install-prompt.tsx`)
- Detects install capability
- Shows custom install UI
- Platform-specific instructions
- Dismissible for 7 days

**4. PWA Metadata**
- Theme color
- Apple web app capable
- Viewport configuration
- Manifest link

**5. Icons**
- 8 icon sizes (72px - 512px)
- SVG format (replace with PNG for production)
- Maskable icons support
- Consistent branding

**6. Offline Page** (`/src/app/offline/page.tsx`)
- Shown when offline
- Try again button
- Clear messaging

### Configuration

**next.config.js:**
```javascript
const withPWA = require('next-pwa')({
  dest: 'public',
  register: true,
  skipWaiting: true,
  disable: process.env.NODE_ENV === 'development',
})
```

**Benefits:**
- Only runs in production
- Auto-generates service worker
- Handles caching strategy
- Updates seamlessly

## 🎨 Customization

### Replace Icons

Current icons are SVG placeholders. For production:

**Option 1: Use a Service**
1. Visit [realfavicongenerator.net](https://realfavicongenerator.net/)
2. Upload your logo (512x512 recommended)
3. Download all sizes
4. Replace files in `/public/icons/`

**Option 2: Use ImageMagick**
```bash
# Convert SVG to PNG at different sizes
convert icon.svg -resize 72x72 icon-72x72.png
convert icon.svg -resize 96x96 icon-96x96.png
# ... repeat for all sizes
```

**Option 3: Use Online Converter**
1. Go to [cloudconvert.com](https://cloudconvert.com/)
2. Upload SVG
3. Convert to PNG at each size
4. Download and replace

### Update Manifest

Edit `/public/manifest.json`:

```json
{
  "name": "Your Store Name",
  "short_name": "Store",
  "description": "Your description",
  "theme_color": "#yourcolor",
  "background_color": "#yourcolor"
}
```

### Customize Install Prompt

Edit `/src/components/pwa-install-prompt.tsx`:

- Change delay before showing (default: 5 seconds)
- Modify dismiss duration (default: 7 days)
- Update text and styling
- Add custom logic

### Future Enhancements

**Push Notifications:**
```javascript
// In service worker
self.addEventListener('push', (event) => {
  const data = event.data.json()
  self.registration.showNotification(data.title, {
    body: data.body,
    icon: '/icons/icon-192x192.png'
  })
})
```

**Background Sync:**
```javascript
// Sync data when connection returns
navigator.serviceWorker.ready.then((registration) => {
  return registration.sync.register('sync-orders')
})
```

## 🔍 Troubleshooting

### Install Prompt Not Showing

**Check:**
- Running on HTTPS (or localhost)
- Service worker registered
- Manifest valid
- Not already installed
- User hasn't dismissed recently

**Solution:**
- Check browser console for errors
- Validate manifest JSON
- Verify service worker in DevTools

### Service Worker Not Updating

**Cause:**
- Old service worker cached
- skipWaiting not enabled

**Solution:**
- Hard refresh (Ctrl+Shift+R)
- Clear service workers in DevTools
- Wait for automatic update (24 hours)

### Offline Mode Not Working

**Check:**
- Service worker active
- Cache strategy correct
- Network tab shows "from ServiceWorker"

**Solution:**
- Re-register service worker
- Clear cache and reload
- Check PWA config

### Icons Not Showing

**Check:**
- Icon files exist in /public/icons/
- Manifest references correct paths
- Icons are correct format (PNG recommended)

**Solution:**
- Convert SVG to PNG
- Verify file names match manifest
- Check file sizes

## 🎯 Best Practices

1. **Keep it Fast**
   - Minimize service worker cache
   - Use efficient caching strategies
   - Pre-cache critical resources

2. **Test on Real Devices**
   - iOS and Android
   - Different browsers
   - Various network speeds

3. **Update Carefully**
   - Test service worker updates
   - Don't break offline experience
   - Clear old caches

4. **Monitor Performance**
   - Lighthouse audits regularly
   - Check Core Web Vitals
   - Track install rates

5. **Provide Value**
   - Make offline experience useful
   - Add app shortcuts
   - Fast, reliable performance
